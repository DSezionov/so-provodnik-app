# Правила работы над Provodnik

Полное ТЗ — в `SPEC.md`. Перед любой задачей сверяйся с ним; если задача ему противоречит — спроси, не импровизируй.

## Принципы

- **Работаем по фазам из SPEC.md §7.** Одна фаза — одна ветка/PR, в конце краткая сводка: что сделано, что не получилось, что дальше.
- **После Фазы 0 обязательно остановись** и покажи `data/report.md` — модель данных утверждается вместе с владельцем.
- **Данные не выдумываем.** Если поле не извлеклось — `confidence: "unknown"`, а не правдоподобная догадка. Никаких «заглушечных» предметов, количеств, локаций.
- **Вежливый парсер:** сначала `robots.txt`; запрещённые пути (`/w/` целиком, включая `api.php`; `Special:`/`Служебная:`; `/wiki/edit/` и др.) не трогаем; источник — только HTML `/wiki/…` и страницы-списки, пока админ вики не разрешит иное; User-Agent `ProvodnikBot/0.1 (+ссылка на репозиторий)`; пауза между запросами — `Crawl-delay` из robots.txt (сейчас 5 с), но не меньше 1 с; кэш на диске; повторный запуск качает только изменившиеся страницы.
- **GitHub Pages:** только статика, hash-router, `base` = `/<имя-репозитория>/`. Проверяй, что сборка и PWA работают именно под подпутём.
- **i18n:** никакого текста интерфейса в JSX — только ключи; при добавлении ключа сразу заполняй `ru`, `uk`, `en`.
- **Mobile-first.** Всё проверяй на ширине 375px.
- Алгоритмы маршрута и чек-листа — чистые функции в `src/lib/` с тестами Vitest. Парсер — с pytest-фикстурами из реальных (закэшированных) страниц.

## Команды

- `npm run dev` — dev-сервер: <http://localhost:5173/so-provodnik-app/>
- `npm run build` — проверка типов + сборка в `dist/` (с service worker)
- `npm run preview` — раздать `dist/` под тем же подпутём (проверка PWA и офлайна)
- `npm test` — Vitest (`src/**/*.test.ts`)
- `npx pwa-assets-generator` — перегенерировать иконки из `public/logo.svg`
- Сборщик: `cd scraper && .venv/bin/python -m pytest tests` — тесты парсера; запуск сборщика — см. `scraper/README.md` (сеть до so-wiki.ru — только через VPN)
- Деплой: push в `main` → workflow `deploy` собирает `dist/` и публикует на Pages. В Settings → Pages источник должен быть **GitHub Actions**: при «Deploy from a branch» публикуется сырой репозиторий и сайт — белый экран.
- Ширина 375px: окно Chrome уже не сжать, проверять через iframe шириной 375px на том же origin
